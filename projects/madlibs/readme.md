# Madlibs!

### Description
A simple madlibs game that allows the user to make some input to create a funny story (or a madlib)

### What I've Learned
I practiced user inputs using mostly `fgets()` and removing the newline in the input buffer by using the `strlen()` function. It was a small and easy little project, but I could improve on it later with some control flow to manage user input more.
