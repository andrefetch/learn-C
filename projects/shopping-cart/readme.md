# Shopping Cart Program

### Description
This is a simple shopping cart program that allows you to type in what you want to buy, the price, and the quantity. And it will print it to the terminal with the correct format specification.

### What I've Learned
What I've learned building this simple project out in C, is first practicing the use of `fgets()` and `scanf()`, and using a way to get rid of the newline that fgets loads into the input buffer. I've also learned how to chain multiple variables in a single `printf()` statement.
