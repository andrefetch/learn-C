# Banking Program

### Description
A simple banking program with a menu that keeps running until you choose to exit. You can check your balance, deposit money, and withdraw money, with the balance carrying over between each option.

### What I've Learned
I practiced combining a `do while` loop with a `switch` statement to build a menu that repeats until the exit option is picked, and using a `default` case to catch invalid choices. I also practiced passing values into functions versus returning them back out, using the returned amount to add to or subtract from the balance in `main()` with `+=` and `-=`. The withdraw function gave me more practice with if/else if chains for validating input, like checking for negative amounts and insufficient funds, and I used `%.2f` to keep the money formatted to two decimal places.
