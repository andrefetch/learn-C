# Compound Interest Calculator

### Description
Simple and small compound interest calculator written in C, uses the `A = P(1 + r/n)^nt` formula to provide an accurate result.

### What I've Learned
More practice with the builtin math functions, more address operations with the `scanf()` function, mostly just trying to concrete my knowledge on these beginner parts of C to understand larger and harder ones.
